# Piece artwork

Classic "cburnett" chess pieces by Colin M.L. Burnett, the same artwork the desktop
version uses (Wikipedia set). Multi-licensed on Wikimedia Commons (GFDL / BSD / GPL);
used here under the BSD license with attribution.

`generate_assets.py` renders them to 256 px PNGs in
`app/src/main/res/drawable-nodpi/piece_*.png`.
